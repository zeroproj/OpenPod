# OpenPod — Reload Alpha 0.1

Fundo preto em todas as telas · Barra Data · OpenPod · Bateria · Atualização por SD

Base: `GN438_original.bin` yp3_2.0.43 — receita `reload_alpha` em `tools/build.py`

> Esta Alpha melhora o que já existe. Não copia outro aparelho.

---

## Instalar

### Windows

Abra `windows/LEIA-ME.txt`. Tudo está em `windows/`, inclusive o gravador.

### Linux / macOS

```sh
sh install.sh
```

Pergunta o idioma e guia a gravação por cabo (6 setores que mudam).

### Depois

Com esta Alpha instalada, as próximas entram por cartão:

`Configurar → Atualizar por SD`

Basta copiar `OpenPod_Reload_Alpha_0.1.up` para a raiz do cartão como `update.up`.
