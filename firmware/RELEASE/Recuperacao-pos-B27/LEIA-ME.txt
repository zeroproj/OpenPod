Recuperação depois do B27 (2026-11-10)

O que aconteceu: o B27_251112.up (outro produto) foi instalado no GN-438.
O aparelho liga, mas nada funciona. O B27 trocou o bootloader, a tabela
de partições e o firmware até 0x1DA038.

Este update.up = RC6 (a versão estável) + bootloader e tabela de fábrica
do GN-438 + a área de 0x1A8000 a 0x1DB000 apagada (0xFF, como no ORIGINAL).
As configurações (PSMP, a partir de 0x1FC000) ficam de fora.
Tamanho 0x1DB100 · CRC 0xB81E · sha256 9f62bdac…

Como gravar (em ordem):
 A) Se o B27 tiver no menu algo como "atualizar firmware/upgrade":
    copie este update.up para a raiz do cartão e use essa opção.
 B) Windows + Flashloader (caminho confirmado em 2026-09-18):
    - Abra o FlashloaderSL-DEV-6.9.5.exe (pasta windows/ de qualquer kit).
    - Selecione ESTE update.up.
    - Ponha o aparelho em modo de gravação: conecte o USB, segure
      VOLUME PARA BAIXO e, sem soltar, aperte o RESET (furinho lateral).
    - Siga docs/TESTE_FLASHLOADER.md.
 Depois: Config -> Informações deve mostrar a RC6.
