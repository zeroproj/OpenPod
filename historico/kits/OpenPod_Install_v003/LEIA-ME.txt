OpenPod_Install — v003
==========================

calibra a luminosidade dos icones

GERADO por tools/make_install_kit.py. Nao edite a mao.
Requisitos: Linux, python3, lsusb, smtlink_dump.


A REGRA QUE NASCEU DE UM ERRO REAL
----------------------------------
  O write_flash grava A PARTIR DO OFFSET 0 DO ARQUIVO.
  O 2o argumento NAO e o offset dentro do arquivo.

  ERRADO  write_flash 0xD000 0xD000 0x1000 imagem_2MiB.bin
  CERTO   write_flash 0xD000 0      0x1000 setor_D000.bin

  Por isso: um arquivo POR SETOR, sempre 0 no 2o argumento.
  Detalhe em docs/WRITE_FLASH_SEMANTICS.md.

COMO RODAR
----------
  sha256sum *.bin          # conferir a transferencia

  sudo sh diag.sh /opt/smartlink_flash        # so leitura
  sudo sh flash_v003.sh /opt/smartlink_flash

NAO precisa plugar antes. Rode o script COM O APARELHO DESLIGADO
ou desconectado: ele espera, avisa a hora de conectar, deixa
estabilizar e pergunta se pode seguir.

Por que assim: o aparelho precisa de alguns segundos entre plugar
e o primeiro comando, senao cai do modo card reader no meio da
operacao. Era por isso que o recovery_check_linux.sh 'funcionava
melhor' — ele gastava tempo compilando antes de falar com o
aparelho. Agora essa folga e explicita.

O script para e pede GRAVAR digitado. Ate ai, so houve leitura.


SE DER ERRADO
-------------
NAO DESLIGUE O APARELHO. Enquanto ele enumera, tem conserto.

  sudo /opt/smartlink_flash/smtlink_dump --id 301a:2801 \
       write_flash 0xD000 0 0x1000 orig_D000.bin
  sudo /opt/smartlink_flash/smtlink_dump --id 301a:2801 \
       write_flash 0xCD000 0 0x1000 orig_CD000.bin
  sudo /opt/smartlink_flash/smtlink_dump --id 301a:2801 \
       write_flash 0xCE000 0 0x1000 orig_CE000.bin

Isso devolve o aparelho ao ORIGINAL DE FABRICA.
