A REGRA QUE NASCEU DE UM ERRO REAL
----------------------------------
  O write_flash grava A PARTIR DO OFFSET 0 DO ARQUIVO.
  O 2o argumento NAO e o offset dentro do arquivo.

  ERRADO  write_flash 0xD000 0xD000 0x1000 imagem_2MiB.bin
  CERTO   write_flash 0xD000 0      0x1000 setor_D000.bin

  Por isso: um arquivo POR SETOR, sempre 0 no 2o argumento.
  Detalhe em docs/WRITE_FLASH_SEMANTICS.md.

COMO RODAR
----------
  sha256sum *.bin          # conferir a transferencia

  sudo sh diag.sh /opt/smartlink_flash        # so leitura
  sudo sh flash_v020.sh /opt/smartlink_flash

ORDEM RECOMENDADA (a que se mostrou mais confiavel):
  1. plugue o aparelho, com o cartao, e espere o raio na tela
  2. espere mais ~10 segundos
  3. SO ENTAO rode o script

O script tambem aceita a ordem inversa — se o aparelho nao estiver
conectado ele espera e avisa a hora de plugar. Mas por esse caminho
o aparelho costuma RE-ENUMERAR logo depois de detectado (observado
em 2026-09-12: Device 094 na espera, Device 098 segundos depois).

Por que a folga importa: o aparelho precisa de alguns segundos
entre plugar e o primeiro comando, senao cai do modo card reader no
meio da operacao. Era por isso que o recovery_check_linux.sh
'funcionava melhor' — ele gastava tempo compilando antes de falar
com o aparelho. Agora essa folga e explicita.

O script para e pede GRAVAR digitado. Ate ai, so houve leitura.


SE DER ERRADO
-------------
NAO DESLIGUE O APARELHO. Enquanto ele enumera, tem conserto.

  sudo /opt/smartlink_flash/smtlink_dump --id 301a:2801 \
       write_flash 0xD000 0 0x1000 base_D000.bin
  sudo /opt/smartlink_flash/smtlink_dump --id 301a:2801 \
       write_flash 0x13A000 0 0x1000 base_13A000.bin
  sudo /opt/smartlink_flash/smtlink_dump --id 301a:2801 \
       write_flash 0x1A3000 0 0x1000 base_1A3000.bin

Isso devolve o aparelho ao estado ANTERIOR — o mesmo que ele tinha
antes deste kit, ja verificado e ja testado bootando.

NAO use setores de fabrica para reverter um patch parcial: o resto
da flash continuaria no estado da base e a FIRM ficaria misturada,
com o CRC da tabela de particoes sem bater. Para voltar de fato ao
ORIGINAL DE FABRICA, use o procedimento completo de recuperacao.
