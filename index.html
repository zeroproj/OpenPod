O que o OpenPod traz

  • Logo do OpenPod na abertura e fundo preto nas telas.
  • Barra superior com degradê: relógio, OpenPod e bateria alinhados.
  • Ícones novos na tela inicial, sem nomes, com moldura branca no item selecionado.
  • Textos em português revisados (sem "ecrã", "ficheiro" e traduções erradas).
  • Atualizar por SD: as próximas versões entram pelo cartão, sem computador.

Como instalar

Só na primeira vez você precisa de um computador com Windows e do cabo USB. Depois, as próximas versões entram pelo cartão SD, direto no aparelho.

Antes de começar
· Só para o Iigenai GN-438. Em outro aparelho, não grave.
· Computador na tomada e cabo USB de dados (cabo só de carga não funciona).
· Deixe conectado só o aparelho que vai gravar.
· As configurações (volume, equalizador, idioma) voltam ao padrão. As músicas do cartão continuam lá.

Primeira instalação — pelo cabo, no Windows

1. Baixe os dois arquivos

OpenPod — versão mais recente (update.up)Gravador Flashloader 6.9.5 (.exe)

O gravador é o programa oficial da Shenju, fabricante do chip do aparelho. Não é do OpenPod.

2. Abra o gravador e deixe em inglês

Abra o FlashloaderSL-DEV-6.9.5.exe. Ele abre em chinês. No menu, vá em setting → Language → English.

3. Configure (uma vez só)

No menu, vá em setting → Develp setting.... Essa janela continua em chinês, então siga pela posição das caixas:

✅ Marqueas três primeiras caixas:
1. 自动下载 — gravar automático
2. 烧录完后自动重启 — reiniciar depois de gravar
3. 烧录完重启后恢复出厂设置 — voltar ao padrão ao reiniciar
⛔ Não marque4. 仅擦除 — só apagar
6. 频偏校准 — apaga dados de calibração
✋ Não mexano tamanho da flash e nos campos de endereço Bluetooth

Clique em Save.

4. Escolha o arquivo do OpenPod

Clique em Select .up file (canto superior direito) e escolha o update.up que você baixou. Confira se o caminho mostrado termina em update.up.

5. Coloque o aparelho no modo de gravação

  1. Ligue o aparelho no USB do computador.
  2. Segure o botão de volume para baixo.
  3. Sem soltar o volume, aperte o botão RESET (o furinho na lateral).
  4. Continue segurando o volume por uns 5 segundos.

A tela do aparelho fica apagada — é assim mesmo. Se o Windows perguntar se quer formatar, responda não e feche a janela.

6. Grave

Clique em Burn e espere a barra chegar a 100%. Não desconecte nada enquanto grava. No fim, o aparelho reinicia sozinho.

7. Confira

No aparelho, abra Config → Informações. Tem que aparecer a versão do OpenPod (começa com Reload). Pronto!

Próximas versões — pelo cartão SD (sem computador)

  1. Baixe a versão mais recente (botão no topo da página). O arquivo já vem com o nome certo: update.up.
  2. Copie o update.up para a raiz do cartão (fora de qualquer pasta).
  3. Coloque o cartão no aparelho e vá em Config → Atualizar por SD → Sim.
  4. O aparelho reinicia, atualiza e volta sozinho.
  5. Apague o update.up do cartão. Se ficar lá, ele tenta atualizar toda vez que liga.

Deu algo errado?

Calma: o modo de gravação (passo 5) fica na memória do próprio chip e funciona mesmo se o aparelho não ligar. Repita os passos 5 e 6 para gravar de novo.

OpenPod é um projeto independente, sem ligação com a Smartlink, a Shenju ou o fabricante do aparelho. Use por sua conta e risco. Esta página distribui só os arquivos de atualização; o código-fonte não é público.

OpenPod

A new firmware for the Iigenai GN-438: clean, modern look, focused on music, built from the stock system.

Download the latest version How to install

What OpenPod brings

  • OpenPod logo at startup and black backgrounds.
  • Gradient top bar: clock, OpenPod and battery aligned.
  • New home icons, no labels, with a white frame on the selected item.
  • Reviewed Portuguese texts (the English texts are the stock ones).
  • Update via SD: future versions install from the card, no computer needed.

The player menus are in Portuguese by default; English is available under Config → Idioma.

How to install

Only the first time you need a Windows computer and the USB cable. After that, new versions install from the SD card, right on the player.

Before you start
· Iigenai GN-438 only. Do not flash any other player.
· Computer plugged into power and a USB data cable (charge-only cables don't work).
· Connect only the player you want to flash.
· Settings (volume, equalizer, language) go back to default. Music on the card is kept.

First install — by cable, on Windows

1. Download both files

OpenPod — latest version (update.up)Flashloader 6.9.5 (.exe)

The flasher is the official tool from Shenju, the chip maker. It is not part of OpenPod.

2. Open the flasher and switch it to English

Open FlashloaderSL-DEV-6.9.5.exe. It opens in Chinese. In the menu, go to setting → Language → English.

3. Configure it (only once)

In the menu, go to setting → Develp setting.... This window stays in Chinese, so go by the position of the boxes:

✅ Checkthe first three boxes:
1. 自动下载 — auto download
2. 烧录完后自动重启 — reboot after burning
3. 烧录完重启后恢复出厂设置 — restore defaults on reboot
⛔ Leave unchecked4. 仅擦除 — erase only
6. 频偏校准 — erases calibration data
✋ Don't touchflash size and the Bluetooth address fields

Click Save.

4. Select the OpenPod file

Click Select .up file (top right) and choose the update.up you downloaded. Check that the path shown ends in update.up.

5. Put the player in flashing mode

  1. Connect the player to the computer's USB.
  2. Hold the volume down button.
  3. While holding volume, press the RESET button (the small hole on the side).
  4. Keep holding volume for about 5 seconds.

The player's screen stays dark — that's expected. If Windows asks to format, answer no and close the window.

6. Flash

Click Burn and wait for the bar to reach 100%. Don't disconnect anything while it writes. At the end the player restarts by itself.

7. Check

On the player, open Config → Informações (Settings → Information). It must show the OpenPod version (it starts with Reload). Done!

Next versions — from the SD card (no computer)

  1. Download the latest version (button at the top). The file already has the right name: update.up.
  2. Copy update.up to the root of the card (not inside any folder).
  3. Put the card in the player and go to Config → Atualizar por SD → Sim (Settings → Update via SD → Yes).
  4. The player restarts, updates and comes back by itself.
  5. Delete update.up from the card. If it stays there, the player tries to update every time it starts.

Something went wrong?

Don't worry: flashing mode (step 5) lives in the chip itself and works even if the player won't start. Repeat steps 5 and 6 to flash again.

OpenPod is an independent project, not affiliated with Smartlink, Shenju or the device maker. Use at your own risk. This page only distributes the update files; the source code is not public.
