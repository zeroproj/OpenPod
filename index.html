O OpenPod é um firmware baseado no yp3_2.0.43, da família Smartlink/YP3 — o sistema que roda em boa parte dos players baratos. Ele reescreve a interface por dentro do firmware original, com a navegação e a tipografia do iPod nano de 2ª geração. Sem trocar o sistema, sem apagar o que já funciona.

OpenPod is a firmware based on yp3_2.0.43, from the Smartlink/YP3 family — the system running inside a good share of cheap players. It rewrites the interface inside the original firmware, with the navigation and typography of the 2nd-generation iPod nano. No new system, nothing working thrown away.

Serve no meu? Testado só no Iigenai GN-438. Outros aparelhos da família Smartlink/YP3 são candidatos — e é você quem decide testar. Cada aparelho precisa do dump do próprio aparelho: gravar o firmware de outro modelo brica. Tire o seu dump antes, e assuma que o risco é seu.

Will it fit mine? Tested on the Iigenai GN-438 only. Other players in the Smartlink/YP3 family are candidates — and testing is your call. Each device needs a dump of its own: flashing another model's firmware bricks it. Take your dump first, and accept that the risk is yours.

O que muda

What changes

A tela inicial de fábrica é uma grade de nove ícones. O OpenPod a transforma numa lista de quatro, e move o resto para um submenu — o mesmo movimento que o iPod nano fazia.

The stock home is a grid of nine icons. OpenPod turns it into a list of four and moves the rest into a submenu — the same move the iPod nano made.

Instalar

Install

A primeira instalação é por computador, porque o firmware de fábrica não tem a opção de atualizar por cartão. O OpenPod passa a ter — então só a primeira vez dá trabalho.

The first install needs a computer, because the stock firmware has no update-by-card option. OpenPod adds one — so only the first time is any work.

Por dentro

Under the hood

Não existe código-fonte, nem datasheet, nem SDK. Tudo abaixo foi desmontado, medido e confirmado no aparelho.

There is no source, no datasheet, no SDK. Everything below was disassembled, measured and confirmed on the device.

  • O código roda direto da flash The code runs straight from flash

    Execução em XIP: endereço de flash + 0xC00000 = endereço em execução. Editar um setor é editar o código que roda.

    Execute in place: flash offset + 0xC00000 = runtime address. Editing a sector edits the code that runs.

  • A navegação é assíncrona Navigation is asynchronous

    Callbacks da interface postam mensagens numa fila; a camada de aplicação consome depois. Chamar a navegação direto do callback trava o aparelho — custou duas imagens para aprender.

    UI callbacks post messages to a queue; the app layer consumes them later. Calling navigation directly from a callback freezes the device — that cost two images to learn.

  • As cores entram invertidas Colours go in pre-swapped

    LV_COLOR_16_SWAP está ligado: o valor RGB565 precisa dos bytes trocados. Provado em tela — uma casca pintada de 0x07E0, que seria verde, saiu vermelha.

    LV_COLOR_16_SWAP is on: the RGB565 value needs its bytes swapped. Proven on screen — a shell painted 0x07E0, which should be green, came out red.

  • O texto da versão corta em 113 px The version string clips at 113 px

    Corte duro, sem quebra de linha. Medido com a tabela de glifos da própria imagem: OpenPod Core 5.7 5.7 5.7 5.7 Public Beta 7 dá 177 px e não cabe.

    Hard clip, no line break. Measured against the image's own glyph table: OpenPod Core 5.7 5.7 5.7 5.7 Public Beta 7 is 177 px and does not fit.

  • A imagem se valida sozinha The image validates itself

    Partições FIRM e TONE protegidas por CRC-16/CCITT-FALSE. O pacote de atualização é reconstruído e conferido byte a byte contra o arquivo de fábrica antes de sair.

    FIRM and TONE partitions are protected by CRC-16/CCITT-FALSE. The update package is rebuilt and checked byte for byte against the factory file before shipping.
