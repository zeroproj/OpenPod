# OpenPod

Um firmware novo para o **Iigenai GN-438**: visual limpo e moderno, foco
em música, feito a partir do sistema de fábrica (yp3_2.0.43).

**Site:** https://zeroproj.github.io/OpenPod/

## Download

Pacote atual: [`release/OpenPod-Reload-1.0-RC6/`](release/OpenPod-Reload-1.0-RC6/)

Instruções no `README.md` do pacote. Windows: `windows/LEIA-ME.txt`.

## Serve no meu aparelho?

Testado **só no Iigenai GN-438**. Outros aparelhos da família
Smartlink/YP3 são candidatos — **e é você quem decide testar**. Cada
aparelho precisa do dump do próprio aparelho: gravar o firmware de outro
modelo brica. Tire o seu dump antes, e assuma que o risco é seu.

## Código-fonte

As ferramentas de análise e o histórico de engenharia reversa **não são
públicos por enquanto**. Este repositório distribui apenas os binários de
atualização e a página do projeto.

## Créditos

Projeto independente, sem ligação com a Smartlink, a Shenju ou o
fabricante do aparelho.

Gravador Linux/macOS: **smartlink_flash**, de Ilya Kurdyukov.
Gravador Windows: **Flashloader SL-DEV 6.9.5**, da Shenju (programa
proprietário do fabricante do chip), em `windows/` do pacote.
Direção visual referenciada no tema **NanoClone**, de Billy Blair
(CC-BY-SA 3.0) — apenas valores de cor medidos, nenhum pixel copiado.

OpenPod modifica o firmware do seu aparelho. Você assume o risco.
